## 1. The object

Conway's nim field below omega^(omega^omega) is the algebraic closure of F_2.
Lenstra/DiMuro give a *choice-free* presentation as a term algebra:

* components `chi_q`, `q` a prime power;
* 2-power components: `chi_{2^k} = 2^(2^(k-1))` (finite nimbers 2, 4, 16, 256, ...)
  with `chi_{2^k}^2 + chi_{2^k} = prod_{j<k} chi_{2^j}` (empty product = 1);
* odd prime `r`: `chi_r^r = alpha_r`, and `chi_{r^k}^r = chi_{r^(k-1)}` for `k >= 2`;
* `alpha_r = kappa_{f(r)} + m_r` where `f(r) = ord_r(2)`,
  `kappa_h = sum_{q in Q(h)} chi_q`, and `m_r` is the finite excess, a finite
  nimber (in practice 0, 1, or 4 = chi_4).
* `Q(h)` (DiMuro): `Q(1) = {}`; for `h > 1` let `q` be the prime-power part of `h`
  at its smallest prime and `g = h/q`; `Q(h) = Q(g) ∪ {q}` if `q` does not divide
  `d(kappa_g)`, else `Q(h) = Q(g)`. Here `d(x) = [F_2(x):F_2]`,
  `d(chi_{2^k}) = 2^k`, `d(chi_{r^k}) = r^k * b_r`, `b_r = d(alpha_r)`,
  `d(kappa_h) = lcm_{q in Q(h)} d(chi_q)`.
  (`census.py` implements this and reproduces all 126 OEIS rows.)

The field generated by a downward-closed set S of components has F_2-basis the
monomials `prod chi_q^{e_q}` with `0 <= e_q < prime(q)`, so its degree is
`prod_{q in S} prime(q)`.

**Excess.** `m_p = min{ m >= 0 : kappa_{f(p)} + m is not a p-th power }`, the
p-th-power test taken in any finite field containing the element (extensions of
2-power degree do not change it).

**The rule (conjecture).** `m_p = 0` if `Q(f(p))` is not a singleton odd prime power
(arm Z); `m_p = 4` if `f(p) = 2*3^k` (arm D); `m_p = 1` otherwise (arm O for
`r != 3`, arm C for `f(p) = 3^k`). For arms O/C/D, the smaller values are
structurally forced to be p-th powers (paper theorem); only the rule value
itself is in question. **A counterexample is a prime p such that
`kappa_{f(p)} + rule(p)` IS a p-th power.**

Known: OEIS A380496 gives `m_p` for `3 <= p <= 709` (all obey the rule);
certificates give `m_719 = m_727 = 1`. Nothing is known for `p >= 733`.
Rows depend on earlier rows: the field for row p uses `alpha_r` for every odd
prime `r` in the closure of `Q(f(p))`; those `r` are all smaller than `p`, and
`E(r) | E(p)` where `E(p) = d(kappa_{f(p)} + rule(p))`.

## 2. Canonicity (why explicit models are legitimate)

The term algebra is a field (Lenstra). Build any explicit model `M` of
`F_{2^E}` (e.g. `F_2[x]/(P)`, any irreducible `P` of degree `E`) and embed the
components one at a time in a dependency order: each new component satisfies a
relation (`y^ell = a` or `y^2 + y = a`) that is irreducible over the subfield
generated so far; **any** root in `M` extends the embedding, and any two
embeddings of the abstract field into `M` differ by an automorphism. Hence
the p-th-power status of `kappa_h + m` is independent of all root choices. The
*same* variable must be used for a component that is shared by several
branches (e.g. `chi_3` in both `alpha_7 = chi_3 + 1` and
`alpha_13 = chi_3 + chi_4`): relative Frobenius phases between components that
share a subfield are pinned by the shared variables and are NOT free. A
composed-sum min polynomial over F_2 of two components with non-coprime
degrees mixes all relative phases and is wrong unless the correct factor is
identified.

## 3. Useful exact facts

* Euler test: for `p | 2^E - 1`, `beta` is a p-th power iff
  `beta^((2^E-1)/p) = 1`.
* Norm reduction: for `h | e | E` with `f(p) = h`,
  `beta^((2^E-1)/p) = N_{E/e}(beta)^((2^e-1)/p)`. So one may test in any
  intermediate field whose degree is a multiple of `h`.
* Kummer layer norm: if `L = K(y)`, `y^R = a`, `[L:K] = R` odd, then
  `N_{L/K}(y + c) = c^R + a` for `c in K`. Artin–Schreier layer `y^2+y=a`:
  `N(y + c) = c^2 + c + a`.
* Chain min polys are free: if `a` generates `K` with min poly `P_a`, and
  `y^R = a` generates degree `R*deg P_a`, then `P_y(X) = P_a(X^R)`;
  `P_{a+1}(X) = P_a(X+1)`; AS: `P_c(X) = P_a(X^2 + X)` when `c^2+c=a`.
  (The 727 certificate is exactly `P_kappa_121(X) = P_alpha_11(X^121)`.)
* **Crossing trick** (used for `m_719`): for a singleton top `chi = chi_R`
  (`R = r^a`) over `K = F_2(alpha_r)` of degree `b`, pick a subfield
  `k ⊂ K` of degree `t` with `f(r) | t`, `s | t` (where `h = R s`) and
  `v_r(2^t - 1) = v_r(2^b - 1)`. Then `alpha = c * a^R` with
  `c = N_{K/k}(alpha)^w ∈ k`, `w ≡ (N/(2^t-1))^{-1} mod r^v`, and
  `a ∈ K`. Put `v = chi/a`, so `v^R = c`, `H = k[V]/(V^R - c)` has degree
  `R t ≥ h`, and `N_{KH/H}(1 + chi) = V^{b/t} f_a(V^{-1})` where `f_a` is the
  char poly of `a` over `k`. The Euler test then runs in `H` (degree 64,261
  for p=719 instead of `E = 1.26e9`). Cost: one root extraction in `K`
  (degree `b`) plus the char poly of `a` over `k`.
  See `experiments/ordinary_719_crossed_certificate.py`,
  `experiments/ordinary_359_hilbert_certificate.py`.

## 4. Census and the search target

`python3 census.py N` (scratch dir) computes, for every prime `p <= N`:
`h = f(p)`, `Q(h)`, arm, rule value, `E(p)`. For `p in (727, 10^4]`:
564 rows arm Z with |Q|=2, 85 arm Z with |Q|=3, 449 arm O (singleton), 1 C, 1 D.
Example trees (`python3 tree.py p`):

```
p=733  h=244 Q=(61,)  arm O  E=3660
p=743  h=371 Q=(7,53) arm Z  E=57876  (chi_7 and chi_53 share chi_3)
p=797  h=796 Q=(199,) arm O  E=394020
p=1031 h=515 Q=(5,103) arm Z E=210120
p=1433 h=179 Q=(179,) arm O  E=3504820  (pure chain 179->89->11->5)
p=4507 h=4506 Q=(751,) arm O E=1126500
```

`E(p)` is huge in general: for `p <= 10^6` the median is 2.7e9; it compounds
along chains.

**Random-model heuristic (speculation, but it drives the search):** if the
selected element behaves like a random element, row p fails with probability
about `1/p`. Every odd prime is a row, so the expected number of failures in
`(727, X]` is `log log X - log log 727` (divergent). Probability of at least
one counterexample: 28% below 1e4, 42% below 1e5, 52% below 1e6 if every row
there is tested. Restricted to cheap rows (all p <= 1e5):

| E budget | rows | P(hit) |
| --- | --- | --- |
| E <= 1e5 | 1392 | 19% |
| E <= 1e6 | 2823 | 27% |
| E <= 1e7 | 4436 | 33% |
| E <= 1e8 | 5875 | 36% |

(all rows to 1e5: 42%). So the value of an algorithm is how much of the
`sum 1/p` mass it can reach per CPU-hour; the small-p rows (733..1e4) carry
the most mass per row.

## 6. Requirements on the engine

1. **Exactness.** No probabilistic step may produce a false "counterexample"
   or silently skip a row. Probabilistic irreducibility or root-finding is
   fine only when the result is checked exactly (e.g. `y^ell == a`).
2. **Canonicity.** Shared components must be the same element; phases between
   components with non-coprime degrees must come from the term algebra.
3. **Validation.** Reproduce every known row: OEIS 3..709 (b-file at
   `src/scalar/big/ordinal/b380496.txt`) plus 719, 727, and the structurally
   forced smaller translates in arms O/C/D. The Rust `Ordinal` type
   (`src/scalar/big/ordinal/`) and `experiments/ordinal_excess_probe.py`'s
   `TermAlgebra` are slow independent references for small fields.
4. **Order.** Rows are processed in increasing p (closure rows first); a
   failure at r changes `alpha_r` (but not field degrees when `m_r` moves
   from 0 to 1) and must propagate.
5. **Certificate on a hit.** A putative counterexample needs a replayable
   certificate: the model, each component's root with its exact relation
   check, and the Euler power equal to 1, ideally reproduced by an
   independent implementation.
