# Exploratory excess probes

These scripts are non-authoritative scratch predecessors of the maintained
top-level excess experiments. They are not run by CI.

Use `../cyclotomic_3k_family.py`, `../ordinal_excess_probe.py`, the maintained
certificate scripts, `writeups/excess.tex`, and `docs/OPEN.md` for the current
interfaces and claim boundary. Triage any file here before reuse; move a useful
result to the maintained top level with guards and an explicit oracle contract.
