# Exploratory audit probes

These scripts are retained as research scratch space. They are not imported by
the package, maintained as a coherent suite, or run by CI. Some are independent
toy implementations; others are bounded spot checks.

Do not cite their output as a current project result. Before reuse, inspect the
script, state its mathematical contract, add input/resource guards, and compare
it with the live Rust API. Promote a useful oracle to the maintained top-level
`experiments/` directory and add it to `docs/VERIFY.md`.
